# End of Year Planning Report Guide

This document describes all reports generated by `eoy_planning_report.py`.

## Usage

```bash
# Full year 2025 (Jan-Dec or YTD)
python3 eoy_planning_report.py --year 2025

# Rolling 12 months (previous 12 complete months)
python3 eoy_planning_report.py --rolling

# Custom date range
python3 eoy_planning_report.py --start 2024-01 --end 2025-11
```

---

## Report Structure

Reports are organised into folders by category:

| Folder | Purpose |
|--------|---------|
| `planning/` | Target models, growth recommendations, Base/Stretch tracking, outreach calendar |
| `seasonality/` | Industry and event type seasonality analysis |
| `industry/` | Industry breakdowns, cross-tabs, price bands, fee structure |
| `cohorts/` | Expansion revenue, cohort curves, dormancy, LTV, tier concentration, activation, gateway migration |
| `geography/` | Regional analysis by postcode area, gateway by region |
| `keywords/` | Event keyword analysis and timing |
| `ppc/` | PPC campaign cohort analysis (requires GA4) |
| `boxoffice/` | Box Office vs Online sales channel analysis |
| Root | Main monthly report and summary |

## Root Level Reports

### `eoy_planning_report_YYYYMMDD.csv`
**Main monthly metrics report**

Per-month metrics including:
- New accounts created
- Activated accounts (created events)
- Tier-qualified accounts (10+ tickets)
- Events with sales
- Total tickets, revenue, fees
- Activation timing (avg days to first event/sale)
- YoY comparison for all metrics

### `_summary.csv`
**Period summary with totals and averages**

Aggregated view of the reporting period with:
- Total and average metrics
- YoY comparison
- Churn/retention metrics

### `_monthly_performance_yoy_comparison.csv`
**Monthly performance 2024 vs 2025**

Side-by-side monthly comparison for charting:
- Live Accounts (unique accounts with sales)
- Events (unique events with sales)
- Tickets (total tickets sold)
- Revenue (total ticket revenue)
- Fees (total fees)
- YoY percentage change for each metric

### `_new_account_conversion_funnel.csv`
**New account conversion funnel by month**

For accounts created in each month of 2024 and 2025:
- Accounts Created
- Created Any Event (has FirstEventCreation)
- Created Paid Event (created event with revenue > 0)
- Sold Free Only (only free ticket sales)
- Sold Paid Tickets (has any paid ticket sale)
- Conversion Rate (Paid) %
- % Free Events / % Paid Events
- Avg Days to First Event
- Avg Days to First Sale
- Activated Within 30 Days %
- Reached T4+ (12m) - Accounts reaching Tier 4+ within 12 months of signup (2024 cohorts only; 2025 shows blank as insufficient data)

Includes TOTAL rows for 2024 and 2025, plus CHANGE row showing differences.

**Note:** The T4+ metric uses a 12-month activity window from signup for fair cohort comparison. 2025 cohorts do not yet have 12 months of data, so this column shows blank for 2025 rows.

### `_average_transaction_metrics_4yr.csv`
**Average and median transaction metrics (2022-2025)**

4-year comparison of key transaction metrics:

| Metric | Description |
|--------|-------------|
| Avg/Median Price Per Ticket | Revenue ÷ tickets (per transaction) |
| Avg/Median Tickets Per Booking | Tickets ÷ transactions |
| Avg/Median Transaction Value (ATV) | Revenue ÷ transactions |
| Avg/Median Fees Per Account | Total fees ÷ unique accounts |
| Avg/Median 12m Value Per Account | Total revenue ÷ unique accounts |

## Additional Analytics

These reports provide deeper insights across multiple dimensions.

### Gateway by Geography (`geography/_gateway_by_region.csv`)
**Payment gateway usage by UK region**

Per-region breakdown showing:
- Total accounts and active accounts per gateway (Default, Stripe Connect, Stripe, PayPal)
- Revenue and fees per gateway
- Primary gateway per region
- Gateway adoption percentages

### Tier Concentration (`cohorts/_tier_concentration.csv`)
**Fee concentration by account tier**

Shows how fees are distributed across tiers:
- Fee totals and percentages per tier
- Cumulative fee percentage (e.g., "Top 20% of accounts generate X% of fees")
- Account counts per tier
- Useful for identifying revenue concentration risk

### Cohort Quality by Month (`cohorts/_cohort_quality_by_month.csv`)
**Account performance by signup month**

Monthly cohort analysis showing:
- Accounts created per month
- Activation rates (% that created events, % that sold tickets)
- Average fees per activated account
- 12-month LTV projections
- Identifies which signup months produce higher-quality accounts

### Outreach Calendar (`planning/_outreach_calendar.csv`, `planning/_monthly_outreach_focus.csv`)
**Recommended outreach timing by event keyword**

Campaign planning tool:
- Peak months for each event keyword
- Recommended outreach months (based on sales lead times)
- Lead time recommendations (days before peak)
- Monthly focus report showing which keywords to target each month

### Price Band Analysis (`industry/_price_band_summary.csv`, `industry/_price_band_by_industry.csv`)
**Event pricing distribution**

Price bands: Free, £1-£9.99, £10-£24.99, £25-£49.99, £50+

Summary report:
- Event counts per price band
- Revenue, tickets, fees per band
- Average ticket price

By industry:
- Price band distribution per industry
- Identifies industries with higher-value events

### Fee Structure Analysis (`industry/_free_vs_paid_by_industry.csv`)
**Free vs paid event split by industry**

Per-industry breakdown:
- Count and percentage of free events
- Count and percentage of paid events
- Total fees from paid events
- Avg fees per paid event
- Identifies industries with high free event usage

### Activation by Signup Month (`cohorts/_activation_by_signup_month.csv`)
**Activation speed by signup month**

Timing analysis showing:
- Average days from signup to first event creation
- Average days from signup to first ticket sale
- Activation rate percentages
- Identifies seasonal patterns in activation speed

### Gateway Migration (`cohorts/_gateway_choice_by_cohort.csv`, `cohorts/_gateway_migration_patterns.csv`)
**Gateway adoption and migration trends**

Cohort-by-cohort gateway analysis:
- First gateway used by cohort year
- Migration patterns (Default → Stripe Connect transitions)
- Migration timing (average days to switch)
- Current gateway distribution by cohort

## Key Metrics Glossary

| Metric | Definition |
|--------|------------|
| New Accounts | Accounts created in the period |
| Activated | Created at least one event |
| Tier Qualified | Sold 10+ tickets (all time) |
| Active Accounts | Accounts with sales in period |
| Events With Sales | Unique events with ticket sales |
| Total Fees | TryBooking revenue (BookingFee + CardFee + TicketFee + ProcessingFee) |
| Total Revenue | Ticket sales (PaymentReceived) |
| Box Office | In-person sales (Card Present or Cash) |
| Base Target | 25,000 cumulative accounts by end of 2026 |
| Stretch Target | 10,000 NEW accounts in 2026 |
| LTV | Lifetime Value (24-month horizon) |
| T4+ | Tier 4 or above (Key Account, High Value, or Tier 4) |
| T4+ (12m) | Accounts reaching T4+ within 12 months of signup (for fair cohort comparison) |
